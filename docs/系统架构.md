# 系统架构

## 整体架构

```
浏览器
  → Caddy（80）
       → 静态前端 (Vue3 + Element Plus)
       → /api/*  → Flask(:5000)
       → /ws     → WebSocket(:8765)
  → SQLite 数据卷 ./data
  → 日志 ./logs
```

## 各组件说明

| 组件 | 作用 | 技术栈 |
|------|------|--------|
| **前端** | 邮箱列表、邮件阅读、OAuth 授权 | Vue3 + Element Plus + Vite |
| **后端 API** | 邮箱增删查改、用户认证、邮件收信 | Flask |
| **WebSocket** | 实时进度推送、列表刷新 | websockets |
| **数据库** | 用户、邮箱、邮件记录、附件 | SQLite |
| **Caddy** | 反向代理 + 静态服务 | Caddy |
| **Outlook OAuth** | 自动续期 + Device Code 授权 | `utils/email/outlook.py` |

## 部署流程

1. `git clone` 项目
2. `./setup-firemail.sh`（生成 JWT、.env）
3. `docker compose up --build -d`
4. 访问 `http://IP:11180/`

## 架构特点

- 单体后端，功能集中
- Docker 多阶段构建（前端 + 后端）
- Caddy 统一入口
- SQLite 单文件数据库，适合小规模

详细说明见 `docs/系统架构.md`。

## 性能优化

- Vite 构建前端
- 批量提交数据库
- Outlook Token 后台巡检
- 实时检查使用 ThreadPoolExecutor
