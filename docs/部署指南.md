# 花火邮箱助手部署指南

本文档提供花火邮箱助手（FireMail）项目的部署说明。当前仓库推荐使用 **Docker Compose + 本地构建** 的方式部署。

项目仓库：`https://github.com/defeatd/firemail-perfect.git`

## 系统要求

- Docker 19.03+
- Docker Compose v2（支持 `docker compose` 命令）
- 至少 1GB RAM
- 至少 10GB 磁盘空间

## Docker Compose 部署（推荐）

### 1. 克隆代码

```bash
git clone https://github.com/defeatd/firemail-perfect.git
cd firemail-perfect
```

### 2.（可选）修改配置

默认配置已可直接启动，核心配置在根目录的 `docker-compose.yml` 中。

常见可调项：

- 端口映射：默认 `11180:80`
- 持久化挂载：默认 `./data`、`./logs`
- 环境变量（详见下文）

### 3. 构建并启动

```bash
docker compose up --build -d
```

启动完成后：

- Web 界面：`http://服务器IP/`
- 健康检查：`http://服务器IP/api/health`

### 4. 查看日志 / 停止服务

```bash
# 查看日志
docker compose logs -f

# 停止并删除容器
docker compose down
```

## 环境变量配置

可以在 `docker-compose.yml` 的 `environment:` 中设置，或在 `.env` 文件中统一管理（Docker Compose 会自动读取）。

常用环境变量：

| 环境变量 | 说明 | 默认值 |
|---------|------|-------|
| JWT_SECRET_KEY | JWT 签名密钥（建议改成随机字符串） | `huohuo_email_secret_key` |
| TZ | 时区 | `Asia/Shanghai` |
| HOST | 绑定地址 | `0.0.0.0` |
| FLASK_PORT | 后端端口（容器内部） | `5000` |
| WS_PORT | WebSocket 端口（容器内部） | `8765` |

> 说明：对外只暴露 80 端口，`/api/*` 与 `/ws` 会由内置的 Caddy 反向代理到后端与 WebSocket 服务。

## 数据持久化

默认将容器内的数据库/数据目录挂载到宿主机：

- `./data:/app/backend/data`
- `./logs:/app/logs`

迁移/备份时，直接备份 `./data` 目录即可。

## 更新升级

### 更新代码并重建

```bash
# 拉取最新代码
git pull

# 重新构建并启动（建议）
docker compose up --build -d
```

如需清理旧镜像/缓存，可自行使用 Docker 的清理命令（按需执行）。

## 常见问题

### 1. 端口冲突

如果 80 端口已被占用，请修改 `docker-compose.yml` 中的端口映射，例如：

```yaml
ports:
  - "8080:80"
```

然后重启：

```bash
docker compose up --build -d
```

### 2. WebSocket 连接问题

请检查：

1. 反向代理是否正确（默认由 Caddy 处理 `/ws`）
2. 浏览器控制台是否有连接错误
3. 服务器安全组/防火墙是否拦截 80 端口

### 3. 权限问题

若 `./data`、`./logs` 目录权限导致容器写入失败，请检查宿主机目录权限并修正（不同系统处理方式不同）。
