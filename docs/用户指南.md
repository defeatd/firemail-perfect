# 用户指南

## 快速上手

1. 克隆项目
2. `./setup-firemail.sh`（可选）
3. 访问 `http://服务器IP:11180/`
4. 注册第一个管理员账户

## 核心功能

- **邮箱管理**：添加 Outlook/IMAP/Gmail/QQ 账号
- **批量导入**：支持 `example@outlook.com----password----client_id----refresh_token` 格式
- **收信**：单账号检查、批量检查、后台实时检查
- **邮件列表**：支持搜索（主题、发件人、正文）、附件下载
- **Outlook 授权**：Device Code 重新授权、Token 自动续期
- **用户管理**：注册（可关闭）、管理员权限、密码修改

## 常见问题

### 无法访问页面
- 防火墙未放行 11180 端口
- `ALLOWED_ORIGINS` 未包含当前访问 URL

### 添加 Outlook 邮箱失败
- 确保 `client_id` 和 `refresh_token` 正确
- 首次添加需使用 Device Code 重新授权

### 实时检查不生效
- 确保邮箱 `enable_realtime_check = 1`
- 管理员才能启动全局实时检查

## 安全注意

- 密码存储已哈希
- JWT 密钥生产环境必须自定义
- 邮箱列表 API 对 `password` 脱敏
